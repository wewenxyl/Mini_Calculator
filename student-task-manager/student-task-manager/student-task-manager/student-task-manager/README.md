# Student Task Manager

##  About the Project

Student Task Manager is a simple web-based system designed to help students organize and manage their school tasks and assignments.

It allows students to add, view, edit, and delete tasks while keeping track of their deadlines and current status.

##  Features

- Add new tasks and assignments
- View saved tasks in a table
- Edit existing tasks
- Delete tasks
- Set task deadlines
- Set task status
- Clear the input form
- Responsive design for mobile devices
- Colorful galaxy-inspired user interface

##  Technologies Used

- HTML
- CSS
- JavaScript

##  Task Information

Each task contains:

- Subject
- Task / Assignment
- Deadline
- Status

### Task Status

- Pending
- In Progress
- Completed

##  Purpose

The purpose of this project is to create a simple and user-friendly task management system that can help students organize their academic responsibilities.
